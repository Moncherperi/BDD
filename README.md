# 📝 Автотесты для Note API (BDD + Patterns)

Проект содержит набор автоматизированных BDD-сценариев для тестирования REST API сервиса заметок (Note API). 
Тесты разработаны с применением фреймворка **Behave** и паттернов проектирования.

## 📦 Структура тестового проекта

* `features/` — папка со спецификациями и кодом тестов:
  * `notes.feature` — 10 BDD-сценариев (успешные и негативные проверки создания, чтения, обновления и удаления заметок).
  * `steps/notes_steps.py` — реализация шагов (Given, When, Then) с универсальными ловушками.
* `environment.py` — конфигурация тестовой среды (настройка клиента и автоматическая очистка базы перед каждым тестом).
* `note_client.py` — клиент для работы с API (паттерн Command / Пульт управления запросами).
* `note_factory.py` — фабрика данных (паттерн Factory для генерации валидных Payload заметок).
* `requirements.txt` — список зависимостей проекта.
* `.gitignore` — файл исключений для чистоты репозитория.

## 🚀 Инструкция по запуску тестов

### 1. Установите зависимости
Убедитесь, что зависимости из файла `requirements.txt` установлены в вашем виртуальном окружении:
```bash
pip install -r requirements.txt
```

### 2. Запустите веб-сервер приложения
Перед запуском тестов убедитесь, что тестируемый сервер заметок FastAPI запущен и доступен по адресу `http://127.0.0.1:8000`.

### 3. Запуск автотестов
Для запуска прогона всех сценариев введите в терминале команду:
```bash
behave
```
